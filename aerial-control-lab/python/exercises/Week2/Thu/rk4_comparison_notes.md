# Euler、RK4 与解析解对比结论

统一使用 NED 向下为正的一维自由落体模型、初始状态 `[z, v_z] = [0, 0]`、
重力加速度 `g = 9.80665 m/s^2` 和终止时间 `2.0 s`。

| dt (s) | Euler 最终 z (m) | Euler 位置绝对误差 (m) | RK4 最终 z (m) | RK4 位置绝对误差 (m) |
|---:|---:|---:|---:|---:|
| 0.1 | 18.6326350 | 0.9806650 | 19.6133000 | 0 |
| 0.05 | 19.1229675 | 0.4903325 | 19.6133000 | 7.1054e-15 |
| 0.01 | 19.5152335 | 0.0980665 | 19.6133000 | 1.4211e-14 |

三组实验中 Euler 和 RK4 的最终速度均为 `19.6133 m/s`。RK4 的位置误差不超过
`1.5e-14 m`，属于双精度浮点舍入量级；这个量级下误差不再随 `dt` 单调变化。

- Euler 在每一步都使用区间起点的速度更新位置，因此持续低估位移；步长减半时，
  最终位置误差也约减半，符合一阶方法的全局误差特征。
- Euler 对速度是准确的，因为加速度是常量，每一步累加的 `g * dt` 没有近似误差。
- RK4 会综合起点、中点和终点的状态变化率。对于本例的常加速度系统，它能够精确
  积分线性变化的速度，因此网格点上的位置和速度都与解析解一致，仅可能残留浮点
  舍入误差。
- 这个结果不能理解为“RK4 对所有模型都零误差”。自由落体模型非常简单；面对非线性
  或快速变化的动力学，RK4 仍会有离散误差，只是通常比相同步长下的 Euler 小很多。

具体数值由 `plot_free_fall_comparison.py` 运行输出，并绘制到
`free_fall_integrator_comparison.png`。
