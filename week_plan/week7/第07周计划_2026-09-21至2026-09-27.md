## 2. 固定模型、接口与实验规格

### 2.1 本周研究的对象

采用刚体质心处的 FRD 机体系，并假设机体坐标轴与惯量主轴重合：

\[
\boldsymbol{\omega}_B=
\begin{bmatrix}
\omega_x\\\omega_y\\\omega_z
\end{bmatrix},
\qquad
J=\operatorname{diag}(J_x,J_y,J_z)
\]

- 状态：三个机体系角速度，单位 `rad/s`。
- 输入：质心处的外力矩 \(\boldsymbol M_B\)，表达在机体系，单位 `N·m`。
- 参数：三个固定主惯量，单位 `kg·m²`。
- 输出：角速度轨迹、角加速度、旋转动能和角动量模长。
- 力矩由工况直接给定；本周不研究电机如何产生力矩。
- 所有工况使用恒定机体系力矩，机体无形变、无阻力矩，不考虑转子额外动力学。

三轴动力学为：

\[
J\dot{\boldsymbol{\omega}}_B
+\boldsymbol{\omega}_B\times(J\boldsymbol{\omega}_B)
=\boldsymbol M_B
\]

因此：

\[
\dot{\boldsymbol{\omega}}_B
=J^{-1}
\left[
\boldsymbol M_B-
\boldsymbol{\omega}_B\times(J\boldsymbol{\omega}_B)
\right]
\]

对角惯量下，分量形式为：

\[
\begin{aligned}
\dot\omega_x&=
\frac{M_x+(J_y-J_z)\omega_y\omega_z}{J_x},\\
\dot\omega_y&=
\frac{M_y+(J_z-J_x)\omega_z\omega_x}{J_y},\\
\dot\omega_z&=
\frac{M_z+(J_x-J_y)\omega_x\omega_y}{J_z}.
\end{aligned}
\]

向量式用于实现，分量式用于独立手算核对。阅读材料只取惯量、角动量和刚体运动方程相关内容，可参考 [Modern Robotics 第 8.2 节](https://modernrobotics.northwestern.edu/nu-gm-book-resource/8-2-dynamics-of-a-single-rigid-body-part-1-of-2/)。

### 2.2 固定教学参数

默认使用：

\[
[J_x,J_y,J_z]=[0.02,0.03,0.04]\ \mathrm{kg\cdot m^2}
\]

这些是便于手算、展示三轴耦合的教学参数，不代表实测四旋翼惯量。

正式演示统一使用：

- 积分方法：现有 `rk4Step`。
- 步长：`0.01 s`。
- 时长：`2 s`。
- 积分：200 次。
- 保存初态和终态：201 个样本。

角速度具有实际大小，**不对角速度状态或角速度导数做归一化。**

### 2.3 最小正式接口

新增 `rotational_dynamics` 模块，放在现有正式核心模块同层目录：

```cpp
struct RotationalParameters {
    Eigen::Vector3d principalInertiaKgM2;
};

struct RotationalInput {
    Eigen::Vector3d momentBodyNm;
};

StateVector angularRateDerivative(
    double timeS,
    const StateVector& angularRateBodyRadps,
    const RotationalParameters& parameters,
    const RotationalInput& input);
```

接口要求：

- 状态和返回导数都为三维，顺序固定为 `[omega_x,omega_y,omega_z]`。
- 拒绝状态维度错误、非有限时间/状态/力矩，以及非正或非有限惯量。
- 返回角加速度，不积分、不打印、不保存文件。
- 保持调用者的状态不变。
- 使用现有 `StateVector` 和 `DerivativeFunction`。
- 对角惯量按分量相除，不建立通用矩阵求逆框架。
- 新源码接入 `aerial_core`，必要检查接入现有 `aerial_core_gtest`。
- 新增一个 `angular_rate_demo`，各工况共用 `runAngularRateCase`。

演示中的工况保存名称、惯量、初始角速度、力矩、步长和步数；样本按值保存时间与角速度。指标汇总只读取已生成的轨迹。

### 2.4 四个正式工况

| 工况 | 初始角速度 `rad/s` | 机体系力矩 `N·m` | 参考结果 |
|---|---|---|---|
| 静止 | `[0,0,0]` | `[0,0,0]` | 全程保持静止 |
| 无力矩主轴转动 | `[0,0,1]` | `[0,0,0]` | 全程保持 `[0,0,1]` |
| 恒定正滚转力矩 | `[0,0,0]` | `[0.01,0,0]` | \(\omega_x(t)=0.5t\)，两秒末为 `[1,0,0]` |
| 无力矩三轴耦合 | `[1,2,3]` | `[0,0,0]` | 初始导数为 `[-3,2,-0.5] rad/s²`；动能与角动量模长保持 |

第四工况使用：

\[
E=\frac12\boldsymbol{\omega}_B^\mathsf TJ\boldsymbol{\omega}_B,
\qquad
H=\left\|J\boldsymbol{\omega}_B\right\|
\]

其初值为：

\[
E_0=0.25\ \mathrm J,\qquad
H_0=\sqrt{0.0184}\approx0.13564660\ \mathrm{kg\cdot m^2/s}
\]

无外力矩时，惯性系角动量保持；机体系中的角动量分量可以变化。本周尚未积分姿态，因此检查角动量模长，不声称已验证惯性系角动量方向。
